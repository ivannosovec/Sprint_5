Цель проекта
Разработать набор автоматизированных тестов для проверки ключевых пользовательских сценариев веб-приложения Stellar Burgers — сервиса по заказу космических бургеров. Тесты должны охватывать функциональность регистрации, авторизации, навигации и работы с конструктором бургеров.
Что необходимо проверить
1. Регистрация
Успешная регистрация

Имя не должно быть пустым

Email в формате логин@домен (например, test@ya.ru)

Пароль минимум 6 символов

Ошибка для некорректного пароля (менее 6 символов)

2. Вход в систему
по кнопке «Войти в аккаунт» на главной странице

через кнопку «Личный кабинет»

через кнопку в форме регистрации

через кнопку в форме восстановления пароля

3. Переход в личный кабинет
по клику на «Личный кабинет»

4. Переход из личного кабинета в конструктор
по клику на «Конструктор»

по клику на логотип Stellar Burgers

5. Выход из аккаунта
по кнопке «Выйти» в личном кабинете

6. Раздел «Конструктор»
Проверить переключение между вкладками:

«Булки»

«Соусы»

«Начинки»
